# Security / Sicherheit

## English

Report vulnerabilities privately through [GitHub vulnerability reporting](https://github.com/deckerweb/post-author-taxonomy/security/advisories/new), including issues in the bundled deckerweb Library or updater. Provide plugin/component versions, WordPress/PHP versions, reproduction steps and impact. Do not include passwords, tokens or personal author content. If the private form is unavailable, do not publish security details in issues or discussions. Coordinate disclosure and fixes privately; no response deadline is promised.

Ordinary bugs and feature questions belong in [Issues](https://github.com/deckerweb/post-author-taxonomy/issues).

## Deutsch

Melde Sicherheitslücken privat über [GitHubs Sicherheitsmeldung](https://github.com/deckerweb/post-author-taxonomy/security/advisories/new), auch bei Problemen in der eingebundenen deckerweb Library oder im Updater. Nenne Plugin-/Komponentenversionen, WordPress/PHP-Versionen, Reproduktionsschritte und Auswirkungen. Übermittle keine Passwörter, Tokens oder persönlichen Autoreninhalte. Ist das private Formular nicht verfügbar, veröffentliche keine Sicherheitsdetails in Issues oder Discussions. Offenlegung und Fix werden vertraulich abgestimmt; keine Reaktionsfrist wird zugesagt.

Normale Fehler und Funktionsfragen gehören in [Issues](https://github.com/deckerweb/post-author-taxonomy/issues).
