# Grafiken und eingebundene Komponenten

[English](ASSETS.md)

Collective ist die ausgewählte Autorengestaltung für Version 1.4.0. Das Motiv im Icon ist zentriert. Banner verwenden native SVG-Formen, einen Vektorverlauf und Schriftpfade aus Space Grotesk; Icons enthalten native Vektorformen und eine gerundete Schnittmaske. Keine Rasterbilder, Schriftdateien oder externen Ressourcen sind eingebettet. PNGs werden aus denselben SVG-Quellen gerendert. GitHub-Banner liegen auf Deutsch/Englisch mit 1280×640 vor; WordPress-Banner sind proportional mittig zugeschnitten auf 1544×500 und 772×250.

[Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) — Copyright 2020 The Space Grotesk Project Authors, SIL Open Font License 1.1. Die Original-Lizenz liegt unter [assets/SpaceGrotesk-OFL.txt](../assets/SpaceGrotesk-OFL.txt) bei. Die Schrift ist kostenlos kommerziell nutzbar; ihre Lizenzbedingungen gelten für die Schriftweitergabe. Schriftdateien werden nicht mitgeliefert.
