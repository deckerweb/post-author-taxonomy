# Artwork and bundled components

[Deutsch](ASSETS-de.md)

Collective is the selected author artwork for version 1.4.0. Its icon motif is centered. Banners use native SVG shapes, a vector gradient and Space Grotesk glyph paths; icons use native vector shapes and a rounded clipping path. No raster images, font files or external resources are embedded. PNGs are rendered from the same SVG sources. GitHub banners are 1280×640 in English/German; WordPress banners are proportional centered crops at 1544×500 and 772×250.

[Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) — Copyright 2020 The Space Grotesk Project Authors, SIL Open Font License 1.1. The original license is included at [assets/SpaceGrotesk-OFL.txt](../assets/SpaceGrotesk-OFL.txt). The font is free to use commercially; the license terms apply to font distribution. No font files are bundled.
