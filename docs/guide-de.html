Post Author Taxonomy

Autoren wie Tags. Gestalte mit deinem Builder.

Schnellstart

  1. Autoren unter Einstellungen → Post Author Taxonomy → Autoren verwalten anlegen.
  2. Einem Beitrag zuweisen.
  3. [pat-authors] oder [pat-author-boxes] im Template einfügen.

Ein Profil auf jeder Seite

[pat-author-box slug="jane-doe"]

Auf einem pat-author-Taxonomie-Archiv verwendet [pat-author-box] automatisch den aktuellen Autor. Auf normalen Seiten id, slug oder name angeben.

Links und Fotos

Lokales Foto und Website beim Bearbeiten des Autors hinterlegen. Kein Benutzerkonto erforderlich. Benutzerrechte und native Autorenzeilen des Themes bleiben unverändert.

Builder-Beispiele

Bricks / Breakdance: Shortcode-Element für Profile; normale Taxonomie-Abfragen für Autorenarchive. Gutenberg: Shortcode-Block oder Core-Beitragstaxonomien. Fotos und Websites liegen in den Term-Metafeldern pat_photo_id und pat_website.

Anforderungen und Updates

WordPress 6.7+, PHP 8.0+. GitHub Release Updater V2 und deckerweb Library 0.2.0 sind enthalten. Online-Katalog-Updates der Library sind optional. ClassicPress wird nicht offiziell unterstützt.
