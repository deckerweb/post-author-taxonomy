Post Author Taxonomy

Authors as tags. Designed in your builder.

Quick start

  1. Create authors under Settings → Post Author Taxonomy → Manage authors.
  2. Assign them to a post.
  3. Insert [pat-authors] or [pat-author-boxes] in your template.

One profile anywhere

[pat-author-box slug="jane-doe"]

On a pat-author taxonomy archive, [pat-author-box] automatically uses the current author. On ordinary pages, specify id, slug or name.

Links and photos

[pat-authors link="none"]
[pat-authors link="website"]
[pat-author-boxes photo="no" website="no"]

Choose a local photo and website on the author's edit screen. No user account is necessary. User permissions and native theme bylines are unchanged.

Builder recipes

Bricks / Breakdance: use a Shortcode element for profiles; use native taxonomy queries for author archives. Gutenberg: use a Shortcode block or Core Post Terms. Photos and websites are stored as pat_photo_id and pat_website term metadata.

Requirements and updates

WordPress 6.7+, PHP 8.0+. GitHub Release Updater V2 and deckerweb Library 0.2.0 are included. Online Library catalog updates are optional. ClassicPress is not officially supported.
